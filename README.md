# Skillset Corpus

A zero-cost-first pipeline for discovering, fetching, deduplicating, and analyzing public AI agent skills and their `SKILL.md` files.

## Goal

Build a verifiable corpus of publicly accessible skills referenced by skills.sh and related public GitHub repositories, with resumable crawling and content-hash deduplication.

## Status

Repository initialized. Discovery and ingestion pipeline will be added on a feature branch before merging to `main`.
